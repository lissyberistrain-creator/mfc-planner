# MFC Planner 8.5 — развёртывание Cloud API

Frontend может оставаться на GitHub Pages.

Backend из папки `backend/` нужно разместить на сервере, где запускается Python/FastAPI.
Для постоянного хранения нужен PostgreSQL.

Переменные окружения backend:

```env
DATABASE_URL=postgresql://USER:PASSWORD@HOST:5432/mfc_planner
CORS_ORIGINS=https://YOUR-GITHUB-USER.github.io
```

После запуска backend:
1. Открой MFC Planner.
2. В поле `Cloud API` вставь публичный HTTPS-адрес backend.
3. Нажми `Проверить сервер`.
4. Зарегистрируйся или войди.
5. Индикатор сверху должен стать `● облако`.

## Проверка, что проект не локальный

Создай облачный проект на одном компьютере, затем войди под тем же аккаунтом на другом.
Проект должен появиться в `Мои облачные планы`.

Очистка localStorage браузера не удаляет облачные проекты.

## Sharing

Ссылка содержит два параметра:
- `share` — секретный токен доступа;
- `api` — адрес Cloud API.

Ссылка `viewer` даёт просмотр.
Ссылка `editor` позволяет сохранять изменения.

Относись к editor-ссылке как к паролю: любой, у кого она есть, может редактировать проект до истечения срока или отзыва ссылки.
