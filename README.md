# MFC Planner 6.5

Полная объединённая версия.

## Возможности
- вся аналитика из предыдущих версий;
- сквозной оборот и автоштат;
- ФОТ, OPEX, CAPEX;
- центральный проход между блоками хранения;
- ручное перемещение и изменение размеров;
- поворот объектов на 90°;
- копирование и удаление;
- добавление кастомных объектов;
- зона курьеров, возвраты, буферы, упаковка, контроль качества, паллетная зона, зарядка ТСД;
- столы, двери, ручные камеры;
- колонны и препятствия;
- автопокрытие камер и проверка мёртвых зон;
- аналитика пути до сборки.

## Исправление 6.1
- исправлена ошибка выбора объектов, из-за которой интерфейс мог переставать реагировать;
- исправлена функция цвета кастомных объектов;
- вкладки и режим изменения размера продолжают работать после выбора объекта;
- добавлен cache-busting для app.js и styles.css, чтобы GitHub Pages не показывал старую версию из кэша;
- добавлено видимое сообщение при будущей JavaScript-ошибке.


## Исправление 6.2
- добавлена отсутствующая функция поворота выбранного объекта;
- добавлены и проверены функции копирования и удаления;
- после поворота объект остаётся в границах помещения;
- центральный проход корректно обновляет свою ширину после поворота;
- системные зоны хранения и ЦП защищены от случайного удаления;
- обновлён cache-busting до 6.2.


## Исправление 6.3
- исправлена ошибка `money is not defined`;
- центральный проход больше не может случайно превратиться в огромную зону;
- ЦП всегда остаётся горизонтальным и проходит через всю зону хранения;
- ЦП можно двигать только вверх/вниз внутри хранения;
- высота ЦП ограничена разумным диапазоном 1.2–2.6 м;
- добавлен авторасчёт рекомендуемой ширины ЦП по целевому потоку и выбранной стратегии;
- добавлена кнопка «ЦП по центру хранения»;
- автопланировка перераспределена: больше места сборке как самому медленному этапу;
- повреждённые размеры из старого localStorage автоматически нормализуются.


## Исправление 6.4
- центральный проход теперь можно поворачивать на 90°;
- горизонтальный ЦП делит хранение на верхний и нижний блоки;
- вертикальный ЦП делит хранение на левый и правый блоки;
- после поворота ЦП автоматически протягивается через всю зону хранения;
- его фактическая площадь пересчитывается по новой ориентации;
- стеллажные блоки после поворота строятся заново;
- количество секций и вместимость пересчитываются автоматически;
- при ручном изменении толщины ЦП меняется правильная сторона: высота для горизонтального и ширина для вертикального;
- при перемещении ЦП ограничивается только нужная ось.


## Исправление 6.5
- при изменении размеров Приёмки, Сборки и Отгрузки граница хранения пересчитывается автоматически;
- уменьшение process-зон отдаёт освободившуюся площадь хранению;
- увеличение process-зон уменьшает хранение;
- стеллажи автоматически перестраиваются по новой геометрии;
- количество секций и вместимость пересчитываются сразу;
- центральный проход автоматически нормализуется внутри новой зоны хранения.
