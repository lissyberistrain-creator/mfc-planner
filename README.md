# MFC Planner 7.4.2 Storage Engine Rewrite

В этой версии реально переписан движок хранения.

## Новая логика улиц
Одна рабочая улица теперь считается как:

`стеллаж + проход + стеллаж`

При параметрах по умолчанию:

`0,5 м + 1,0 м + 0,5 м = 2,0 м`

Для каждого продольного сегмента секция добавляется только тогда, когда:
- помещается стеллаж с первой стороны;
- свободен рабочий проход между рядами;
- помещается стеллаж со второй стороны.

То есть одна улица всегда имеет две рабочие стороны.

## Заполнение свободной площади
Алгоритм больше не начинает хранение «справа от коридора персонала».

Вся внутренняя площадь помещения является потенциальной складской площадью.
Из неё динамически вычитаются фактические позиции:
- приемки;
- отгрузки;
- офисов;
- WC;
- раздевалок;
- коридоров;
- ЦП;
- колонн;
- пользовательских объектов.

Если объект переместить, его старое место сразу снова становится доступно для стеллажных улиц.

## Поиск лучшего размещения
Для горизонтальных и вертикальных улиц проверяется несколько сдвигов сетки.
Выбирается вариант с максимальным количеством фактически помещающихся секций.

## Центральный проход
ЦП теперь опционален:
- его можно перемещать;
- изменять;
- удалить;
- кнопка «ЦП по центру хранения» восстановит его, если он был удален.

## Терминология
В пользовательском интерфейсе `SKU` заменено на `ШК`.


# MFC Planner 7.4.3 — Smart Zones & Projects

Версия построена поверх рабочего Storage Engine 7.4.2.

## Сохранение планов
- кнопка «Сохранить план» запрашивает название;
- сохранённые планы появляются в выпадающем списке в шапке;
- можно переключаться между планами;
- можно создать копию текущего плана;
- можно удалить выбранный план;
- выбранный сохранённый план автоматически сохраняется каждые 15 секунд;
- обычный «Сбросить» не удаляет библиотеку сохранённых планов.

Сохраняется всё состояние проекта: размеры помещения, зоны, колонны, пользовательские объекты, параметры стеллажей, нормы, персонал и экономика.

## Умные зоны
Для зоны или пользовательского объекта теперь отдельно задаются:
- визуальный тип;
- роль при оптимизации: жёсткое препятствие / процесс / сервис / опциональная;
- флаг «занимает площадь для стеллажей».

Если снять «занимает площадь для стеллажей», Storage Engine сможет использовать эту область при автозаполнении. Это позволяет моделировать варианты, где WC, офис, коридор, буфер или другая зона вынесены за основной склад либо временно не учитываются.

## Совместимость
Старые проекты автоматически получают роли зон и сохраняют прежнюю физическую геометрию, пока пользователь сам не изменит флаг блокировки хранения.

# MFC Planner 7.4.4 — Multiple Plans + Layout Variants

## Исправлено сохранение нескольких планов
В 7.4.3 кнопка «Сохранить план» после первого сохранения всегда обновляла текущий ID, даже если пользователь вводил новое название.

Теперь:
- то же название текущего плана → обновляет его;
- новое название → создаёт новый самостоятельный план;
- «Сохранить как» всегда создаёт новый план;
- планы можно переключать через выпадающий список;
- библиотека проектов мигрирует из 7.4.3.

## Лёгкий оптимизатор вариантов
Добавлен отдельный блок «Варианты планировки».

Он проверяет ограниченное число геометрических сценариев без тяжёлой симуляции камер:
- вариант без ЦП;
- вертикальный и горизонтальный ЦП;
- ширины 1,0 / 1,2 / 1,4 / 1,6 м;
- несколько положений ЦП.

Показываются три сценария:
- Максимум хранения;
- Баланс;
- Максимальный поток.

Для каждого выводятся:
- стеллажные секции;
- вместимость в ШК;
- количество улиц;
- свободная площадь;
- ориентация стеллажей и ЦП.

«Максимум хранения» выбирается фактически по максимальному количеству секций среди проверенных сценариев, поэтому Баланс больше не может случайно иметь больше хранения, чем сценарий с таким названием.
