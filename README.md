# MFC Planner 2.0 — GitHub Pages

Статическая версия MFC Planner. Сервер, Python и Node.js не нужны.

## Что нового в 2.0
- автоматический расчет минимального и рекомендуемого количества операторов на смену;
- расчет строится по сквозному потоку через приемку, раскладку, сборку и отгрузку;
- эмулятор пропускной способности текущей команды;
- расчет максимального сквозного потока команды;
- отображение трудоемкости каждого процесса и узкого места;
- автоматическое зонирование помещения исходя из площади и целевого потока;
- три стратегии: максимум хранения, сбалансированная, максимум пропускной способности;
- автоматический выбор ориентации стеллажей с большей вместимостью.

## Обновление существующего сайта
В репозитории GitHub замените:
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

После Commit changes GitHub Pages обновится автоматически.

## Важно
Авторазмещение является планировочной эвристикой для моделирования. Оно не заменяет проверку пожарных, эвакуационных, строительных и локальных складских нормативов.

Норма отгрузки 3 500 SKU/смену является редактируемым плановым допущением, потому что точная норма ранее не была зафиксирована.
