# MFC Planner 6.0

Полная объединённая версия.

## Возможности
- вся аналитика из предыдущих версий;
- сквозной оборот и автоштат;
- ФОТ, OPEX, CAPEX;
- центральный проход между блоками хранения;
- ручное перемещение и изменение размеров;
- поворот объектов на 90°;
- копирование и удаление;
- добавление кастомных объектов;
- зона курьеров, возвраты, буферы, упаковка, контроль качества, паллетная зона, зарядка ТСД;
- столы, двери, ручные камеры;
- колонны и препятствия;
- автопокрытие камер и проверка мёртвых зон;
- аналитика пути до сборки.
