# MFC Planner 5.0

Главные изменения:
- центральный проход физически делит хранение на два блока;
- стеллажи строятся отдельно выше и ниже центрального прохода;
- центральный проход можно двигать мышкой;
- приёмку, сборку, отгрузку, офис, раздевалку, WC, входы и выходы можно двигать;
- зоны можно менять по размеру;
- колонны можно добавлять, двигать и менять по размеру;
- добавлена оценка длины пути от центра хранения до сборки;
- сохранён автоподбор камер и проверка мёртвых зон.
