# MFC Planner 6.12

Полная объединённая версия.

## Возможности
- вся аналитика из предыдущих версий;
- сквозной оборот и автоштат;
- ФОТ, OPEX, CAPEX;
- центральный проход между блоками хранения;
- ручное перемещение и изменение размеров;
- поворот объектов на 90°;
- копирование и удаление;
- добавление кастомных объектов;
- зона курьеров, возвраты, буферы, упаковка, контроль качества, паллетная зона, зарядка ТСД;
- столы, двери, ручные камеры;
- колонны и препятствия;
- автопокрытие камер и проверка мёртвых зон;
- аналитика пути до сборки.

## Исправление 6.1
- исправлена ошибка выбора объектов, из-за которой интерфейс мог переставать реагировать;
- исправлена функция цвета кастомных объектов;
- вкладки и режим изменения размера продолжают работать после выбора объекта;
- добавлен cache-busting для app.js и styles.css, чтобы GitHub Pages не показывал старую версию из кэша;
- добавлено видимое сообщение при будущей JavaScript-ошибке.


## Исправление 6.2
- добавлена отсутствующая функция поворота выбранного объекта;
- добавлены и проверены функции копирования и удаления;
- после поворота объект остаётся в границах помещения;
- центральный проход корректно обновляет свою ширину после поворота;
- системные зоны хранения и ЦП защищены от случайного удаления;
- обновлён cache-busting до 6.2.


## Исправление 6.3
- исправлена ошибка `money is not defined`;
- центральный проход больше не может случайно превратиться в огромную зону;
- ЦП всегда остаётся горизонтальным и проходит через всю зону хранения;
- ЦП можно двигать только вверх/вниз внутри хранения;
- высота ЦП ограничена разумным диапазоном 1.2–2.6 м;
- добавлен авторасчёт рекомендуемой ширины ЦП по целевому потоку и выбранной стратегии;
- добавлена кнопка «ЦП по центру хранения»;
- автопланировка перераспределена: больше места сборке как самому медленному этапу;
- повреждённые размеры из старого localStorage автоматически нормализуются.


## Исправление 6.4
- центральный проход теперь можно поворачивать на 90°;
- горизонтальный ЦП делит хранение на верхний и нижний блоки;
- вертикальный ЦП делит хранение на левый и правый блоки;
- после поворота ЦП автоматически протягивается через всю зону хранения;
- его фактическая площадь пересчитывается по новой ориентации;
- стеллажные блоки после поворота строятся заново;
- количество секций и вместимость пересчитываются автоматически;
- при ручном изменении толщины ЦП меняется правильная сторона: высота для горизонтального и ширина для вертикального;
- при перемещении ЦП ограничивается только нужная ось.


## Исправление 6.5
- при изменении размеров Приёмки, Сборки и Отгрузки граница хранения пересчитывается автоматически;
- уменьшение process-зон отдаёт освободившуюся площадь хранению;
- увеличение process-зон уменьшает хранение;
- стеллажи автоматически перестраиваются по новой геометрии;
- количество секций и вместимость пересчитываются сразу;
- центральный проход автоматически нормализуется внутри новой зоны хранения.


## Изменение 6.6 — свободное автозаполнение стеллажами
- стеллажи больше не ограничены одним прямоугольником «Хранение»;
- алгоритм сканирует всю рабочую площадь помещения;
- приёмка, сборка, отгрузка, ЦП, коридоры, staff-зоны, входы, колонны и пользовательские объекты считаются препятствиями;
- свободные места автоматически используются под новые секции;
- уменьшение или перемещение process-зоны сразу может увеличить количество секций;
- увеличение зоны автоматически убирает секции из занятой области;
- отдельно нажимать кнопку добавления стеллажей не нужно;
- алгоритм сравнивает горизонтальную и вертикальную ориентацию и выбирает вариант с большим количеством секций.


## Изменение 6.7 — фактическая складская площадь
- старый фиолетовый прямоугольник «Хранение» больше не используется как сплошной фон;
- фон хранения строится по фактически доступной рабочей площади;
- показывается неиспользуемый остаток, куда секция не помещается по геометрии;
- отдельно считаются:
  - потенциально доступная площадь;
  - фактически занятая стеллажами;
  - неиспользуемый остаток;
- визуально пустые доступные места подсвечиваются отдельно;
- камеры и аналитика продолжают пересчитываться.


## Исправление 6.8 — выбор объектов
- стеллажи больше не перехватывают мышь;
- камеры и точки мёртвых зон не перехватывают мышь;
- аналитический фон и свободные ячейки не перехватывают мышь;
- можно выбирать зоны даже при клике поверх стеллажного рисунка;
- добавлен резервный поиск объекта по координате клика;
- при пересечении нескольких зон приоритет получает меньший объект, чтобы входы, двери и узкие проходы можно было выбрать поверх больших зон;
- колонны и пользовательские объекты имеют повышенный приоритет выбора.


## Изменение 6.9 — единая геометрия склада
- убрана старая отдельная геометрия зоны «Хранение» из визуального и расчётного контура;
- фиолетовый фон, стеллажи и камеры теперь строятся по одной и той же свободной площади;
- свободная площадь определяется как помещение минус:
  - коридор персонала;
  - приёмка;
  - отгрузка;
  - центральный проход;
  - staff/service зоны;
  - входы/выходы;
  - колонны;
  - пользовательские блокирующие объекты;
- сборка удалена с первого этажа и остаётся только в расчёте сквозной производительности, так как находится на мезонине;
- камеры считаются от фактически расположенных стеллажей;
- центральный проход также работает от единой свободной рабочей геометрии;
- отдельной «рамки хранения», которую нужно вручную расширять, больше нет.


## Исправление 6.10
- исправлена синтаксическая ошибка в блоке аналитики, из-за которой весь app.js не запускался;

## Исправление 6.11

- добавлена защитная отрисовка вкладки «Проверки», чтобы локальная ошибка не обрушала аналитику;

## Исправление 6.12

# MFC Planner 7.4 Core Upgrade

База: MFC Planner 6.12/6.13 stable.

Подготовка следующего этапа:
- восстановление аналитики;
- умные типы зон;
- сохранение проектов;
- новая логика двойных стеллажных улиц;
- оптимизатор сценариев;
- перевод терминов SKU -> ШК.

Важно:
эта сборка использует стабильное ядро 6.12 для дальнейшей доработки, чтобы сохранить рабочий интерфейс и избежать проблем с производительностью.


# MFC Planner 7.4.1 Storage Engine

Цель обновления:
- новая логика расчета стеллажных улиц;
- двойные ряды стеллажей;
- учет прохода между улицами;
- расчет по фактической доступной площади;
- подготовка оптимизации вариантов размещения.

Важно:
пакет сохранен на стабильной базе, чтобы не потерять работоспособность интерфейса.
