# MFC Planner 4.0 — GitHub Pages

## Что добавлено
- автоматическое покрытие складской зоны камерами;
- проверка мёртвых зон по контрольным точкам;
- учёт колонн и препятствий как занимающих площадь и блокирующих обзор камеры объектов;
- отдельный блок для ввода колонн;
- отображение не покрытых камерой точек на плане;
- сохранён расчёт штатного состава, сквозной пропускной способности, оборудования и аналитики.

## Как обновить сайт
В репозитории GitHub замени 4 файла:
- index.html
- app.js
- styles.css
- README.md

Ничего удалять отдельно не нужно. Просто загрузи новые файлы поверх старых и нажми Commit changes.

## Важно
Алгоритм камер использует:
- дальность камеры;
- простую геометрическую модель покрытия;
- проверку прямой видимости с учётом колонн.

Это хорошая проектная модель для планирования, но для реального внедрения всё равно нужно уточнять:
- конкретную модель камеры;
- угол обзора;
- высоту установки;
- реальные мёртвые зоны;
- требования ИБ и видеонаблюдения на объекте.
