# MFC Planner — GitHub Pages

Статическая версия MFC Planner. Сервер, Python и Node.js не нужны.

## Что внутри
- визуальный план помещения;
- перетаскивание зон мышкой;
- редактирование размеров зон;
- автоматическая раскладка стеллажей внутри зоны хранения;
- расчёт секций, полезного объёма и вместимости;
- расчёт 1 оборота рабочего стока за 30 дней;
- сценарии 100 000 и 120 000 SKU/мес;
- персонал и ФОТ;
- CAPEX, OPEX, хранение и приёмка;
- проверки пересечений и ширины прохода;
- сохранение в браузере;
- экспорт/импорт проекта в JSON.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `mfc-planner`.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `app.js` и `README.md`.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)`.
6. Нажмите `Save`.
7. Через 1–3 минуты GitHub покажет публичный адрес сайта вида:
   `https://USERNAME.github.io/mfc-planner/`

## Важно
Расчёт секций в текущей версии выполняется геометрически по зоне хранения: ряды формируются с учётом глубины стеллажа и ширины прохода, секции в ряду — по длине секции.
