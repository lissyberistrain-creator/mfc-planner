# MFC Planner 8.1 — Cloud Database + Wall Gaps

Версия 8.1 собрана поверх Cloud Workspace Base.

## Что реально работает

### Облачные проекты
Frontend умеет:
- указать URL Cloud API;
- проверить доступность сервера;
- зарегистрировать пользователя;
- войти в аккаунт;
- получать только свои проекты;
- создавать облачные проекты;
- открывать их;
- обновлять;
- удалять;
- автосохранять активный проект на сервер;
- перенести существующие локальные планы в облачный аккаунт.

В интерфейсе есть явный статус:
- `● локально`;
- `● облако`.

Когда пользователь вошёл, подпись под проектом указывает сервер и время последней синхронизации.

`localStorage` остаётся только как резервный черновик и для старых локальных проектов.
Именованные проекты при активной Cloud-сессии сохраняются через API в базу данных.

### Backend
`backend/main.py` содержит:
- FastAPI;
- регистрацию и вход;
- безопасное PBKDF2-хеширование паролей;
- случайные 30-дневные bearer-сессии;
- разграничение проектов по владельцу;
- CRUD проектов;
- SQLAlchemy;
- PostgreSQL через `DATABASE_URL`;
- SQLite fallback только для локальной разработки.

### PostgreSQL
Для реального облачного режима backend нужно развернуть на сервере и передать ему PostgreSQL `DATABASE_URL`.
В комплекте есть:
- `backend/.env.example`;
- `backend/Dockerfile`;
- `docker-compose.yml`.

## Боковые интервалы от стен

В блоке «Стеллажи» появилась кнопка:

`Боковые интервалы от стен: ВКЛ / ВЫКЛ`

При ВКЛ используется значение «Отступ слева / справа, м».
При ВЫКЛ боковой отступ становится 0 м.

Изменение сразу влияет на:
- доступную геометрию хранения;
- количество улиц;
- количество секций;
- ШК;
- Optimizer.

Это планировочная настройка. Отключение отступа не означает автоматического соответствия строительным, пожарным или эксплуатационным требованиям.

## Площадь хранения

В верхних KPI вместо площади второго уровня показана «Площадь хранения».
Это фактическая площадь footprint стеллажей, то есть площадь, где физически располагается товар, без проходов между стеллажными улицами.

## Быстрый локальный тест Cloud API

```bash
docker compose up --build
```

API:
`http://localhost:8000`

Health:
`http://localhost:8000/health`

После этого открой frontend и укажи `http://localhost:8000` в поле Cloud API.

## Для доступа с другого компьютера

`localhost` недостаточно. Backend и PostgreSQL должны быть размещены в интернете по HTTPS.
После развертывания укажи публичный HTTPS URL API в MFC Planner.

GitHub Pages может продолжать хостить frontend, но сам по себе GitHub Pages не запускает FastAPI/PostgreSQL.
